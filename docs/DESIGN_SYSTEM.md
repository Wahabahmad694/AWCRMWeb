# A.W CRM design system

The foundation uses a deep navy `#052c49` sidebar, active blue `#0a5cb7`, primary blue `#0b63ce`, teal `#0f9e91`, page gray `#f5f7fb`, white cards, and border gray `#e4eaf2`. Typography uses system sans fonts to avoid network dependency during builds. Desktop has a fixed sidebar and four metric columns, medium screens have two columns, and mobile has a bottom navigation. Keyboard focus is visible and reduced motion is honored.

Numbers are intentionally absent until authorized report responses are available. An em dash means unavailable; it is never treated as zero.
